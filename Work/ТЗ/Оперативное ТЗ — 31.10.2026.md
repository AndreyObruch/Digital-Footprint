# Оперативное ТЗ — 31.10.2026
Проект: **Digital‑Footprint** («Цифровой след») — поиск следов предков в оцифрованных открытых архивах, каждая находка со ссылкой на первоисточник.

## Задачи (7 шагов, одно действие за раз)
1. **Понять, что сервер умеет сейчас.** Прочитать его код и в облачном редакторе проверить, какие запросы он принимает и что отвечает сегодня. Точка старта — по факту, без догадок.
2. **Наполнить пустой индекс первыми записями.** Внести 5–10 находок, проверенных руками в открытых архивах, каждая со ссылкой на источник. На пустом индексе искать нечего.
3. **Научить сервер искать по индексу.** Чтобы на обычные слова (фамилия, имя, примерный год, место) он возвращал подходящие записи со ссылками, а если ничего нет — честно говорил «не найдено», без выдуманных версий.
4. **Сделать простую страницу для человека.** Одно поле для вопроса и список находок со ссылками, чтобы сервисом пользовался не специалист.
5. **Собрать автопроверки в один запуск.** Оставить已有的 проверку индекса и добавить проверку поиска, чтобы после любой правки одной командой видеть: зелёное или сломалось.
6. **Обновить досье проекта (DOSSIER.md).** Записать, что правки ходят через облачный редактор, локальный git на ноутбуке в GitHub не отправляется, и какой сейчас статус каждой части; поднять версию.
7. **Получить постоянный внешний адрес.** Настроить домен на хостинге, чтобы приложение открывалось в браузере без ноутбука, и проверить поиск по этому адресу.

## Правила работы
- Одно действие за раз: команда → выполнение → результат → только потом следующее.
- Код и индекс правим в облачном редакторе GitHub; notepad++ на ноутбуке — только читать локальную копию.
- Если нужна замена файла — присылаю целый файл и полный путь к локальной копии для notepad++.
- Сообщения для коммитов присылаю текстом, ты вставляешь и отправляешь в GitHub сам.
- Локальный git на ноутбуке в GitHub не пушим (сеть не пропускает) — только через облачный редактор.

## Принципы продукта (держать в голове на каждом шаге)
- У каждой находки есть ссылка на источник.
- Если ничего не найдено — говорим прямо, без версий и домыслов.
- Специальные знания от пользователя не требуются.
